# Interfaces — contracts between teams

One page per seam between two or more teams (`type: interface`, `teams: [a, b]`): who provides what, how to ask,
how each side checks its own half, and which symptoms on one side are usually caused on the other.
Start from `templates/interface.md`. Every team in `teams:` approves changes. Design: `docs/it-brain/ARCHITECTURE.md` §3.2.

All pages here are drafts (`confidence: hypothesis`) until the teams fill the `<…>` cells.
